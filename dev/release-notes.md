Перерывы в Childgram с настройкой времени.

• В родительском контроле появился режим «Затемнять экран, когда пора отдохнуть». По умолчанию он выключен.
• Родитель выбирает, когда показать подсказку, сколько времени экран будет темнеть и сколько займёт самый длинный перерыв. Начальные значения — 10, 10 и 5 минут. Для быстрой пробы можно поставить по одной минуте.
• Подсказка плавно движется по экрану. Её можно отодвинуть пальцем или нажать, чтобы начать перерыв. При полном затемнении нажатия по скрытому интерфейсу блокируются.
• Короткие паузы засчитываются с первой секунды. Если вернуться раньше, уже пройденная часть перерыва сохраняется. Звонки остаются доступны и приостанавливают счётчик.
• Улучшено открытие ссылок и мини-приложений после проверки родительских ограничений.
• Требуется Android 6.0 или новее. Сборка предназначена для ARM64.

Устанавливайте поверх предыдущей версии, без удаления приложения.
